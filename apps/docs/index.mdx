## What Lane4 HQ is for

Lane4 HQ is coach software for the team attending a meet. It does not merge other teams' entry packs, run the timing console, or provide family accounts, messaging, or dues. Host teams run the meet on deck in Lane4 Meet Manager, which has its own guide.

## Need help?

Start with the guide for the screen you are using. If a file will not import, include the file type and the step that failed when you contact support.
