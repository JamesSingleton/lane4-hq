# Plan workouts

Workouts holds the practice plans for the team you have open. A club workout and a high-school workout do not overwrite each other, because each plan belongs to one team.

<video controls src="/videos/workouts.mp4" width="100%" />

## Create a workout

1. Open Workouts.
2. Choose New workout.
3. Give it a title a coach will recognize on deck, then add the sets.
4. The distance total shows on the library row after you save.

## Keep plans useful on deck

Write the workout so another coach can run it. Put the intent, the sendoff or interval, and any group change in the set notes. This library is for the coaching staff, not a feed for families.
