# Prepare entries and import results

The entries tab is where you decide who is swimming. Results is where those swims come back after the meet.

## Build entries

Start from the roster and the event list. Lane4 can use a swimmer's best time as the seed. You can still change the seed for this meet. The program lists each event and how many athletes are in it. The cap for the meet, such as two individual events and two relays, stays above the list.

For relays, pick the swimmers and check the order before you export. Lineup and relay tools depend on the team's plan.

## Review and export

Before you send a file to the host:

1. Check events, entry limits, and scratches.
2. Check relay swimmers and seed times.
3. Export the HY3, CL2, or SDIF file the host asked for.
4. Print entries or a split sheet if the staff wants paper on deck.

## Bring results back

Import HY3, CL2, SDIF, or a ZIP of results after the meet. You can also add a single time by hand, including an exhibition swim. Filters on the results page limit the list to personal bests or compare each swim with a time standard.

Watch unmatched rows. A result that Lane4 cannot tie to a swimmer will not update a best time.
