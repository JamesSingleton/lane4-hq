# Manage the roster

Roster is where you add swimmers, keep season details current, and sort the team into groups. The season selector at the top chooses which year you are looking at.

<video controls src="/videos/roster.mp4" width="100%" />

## Add swimmers

Open Roster, then Swimmers. Add a swimmer, or import a file if the team already has a roster somewhere else. High-school teams track class year. Club teams can keep a USA Swimming ID. Update the group or status when it changes.

## Organize groups and coaches

Use the Groups and Coaches tabs on the roster. Groups make practice and entries easier to scan. Coaches lists the staff connected to this team.

## Import and export

Import and Export roster sit above the table. Lane4 accepts its own share pack (`.lane4hq.json`), plus CSV, SD3, CL2, HY3, and roster ZIP files.

<Warning>
  Check the import mapping and any unmatched rows before you treat the import as finished. An unsupported file, or a row missing the field Lane4 uses to recognize a swimmer, will not match.
</Warning>
