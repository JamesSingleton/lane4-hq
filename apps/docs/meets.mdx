# Run your team’s meet workflow

Lane4 HQ helps the visiting team prepare its own roster, entries, and results. It does not host a meet, merge other clubs’ entry files, or replace a timing console. Host teams run the meet itself in the <a href="/desktop-app">desktop meet manager</a>.

## Create or import a meet

Create a meet from **Meets → Add meet**, then add its details manually or import the event file the host provided. An imported event file can bring in sessions, events, divisions, and qualifying times.

## Work through the meet hub

Once the meet exists, use its navigation to:

- review events and sessions;
- manage individual entries and relays;
- prepare a report for coaches;
- import results after the meet.

<Note>
  Lane4 HQ supports swim events. Diving events are skipped so a swim-only team can continue working with the meet file.
</Note>
