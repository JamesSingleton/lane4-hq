# Work with meet files

Lane4 HQ uses the files meet software already exchanges. Choose the file that matches the host’s request and the point in your workflow.

## Supported interchange

| Format | Typical use |
| --- | --- |
| HY3 | Meet Manager entry and result packs |
| CL2 | Legacy entry and result packs |
| EV3 | Event files with sessions, events, and qualifying times |
| HYV | Invitational event files |
| SDIF / SD3 | Interchange with TeamUnify, SwimTopia, and other swim software |
| XLS | Meet Manager event reports |
| ZIP | Packs containing supported event, entry, or result files |

## Before importing

1. Confirm that the file is for the same meet and team workflow you expect.
2. Keep the original download until the import is reviewed.
3. Select the file from the meet import flow and address any reported unmatched records.

## Verify course and deadline

The import review shows the host’s meet course and entry deadline. Confirm both before completing the import.

On a CL2 file the meet course is the single letter at the end of the meet
line (`Y` yards, `S` short-course meters, `L` long course). Words in the
facility name are not a course. Each swimmer’s entry time keeps its own
course letter, so a yards seed stays yards even when you are checking a
different meet line.

On an HY3 file the age-up date is separate from the meet start. Lane4
keeps that date and uses it when it writes the file back out. A CL2
“individual info” line after a swimmer’s first entry carries a USA
Swimming id and a preferred first name when Team Manager exported them.
On a CL2 results file, prelim, swim-off, and finals times stay on the
swimmer line when a later split line repeats one of them.

Hy-Tek course codes can describe an **entry-time policy**, rather than the
physical pool. For example, `Y`, `YO`, `YSL`, and `YLS` tell Team Manager how
to choose or convert a swimmer’s entry time. They do not, by themselves,
identify whether the meet is swum in SCY, SCM, or LCM. Set the course to the
actual competition pool in the review when needed.

<Note>
  Multi-course policies such as `YLS` and `YSL` prioritize qualifying times
  across multiple courses. Lane4 HQ currently supports a single
  competition course for meet events; verify the host’s entry rules and
  qualifying standards before submitting entries for a multi-course-cut meet.
</Note>

The host entry deadline must be a real deadline supplied by the host. Do not
assume that a same-day date is correct—confirm it with the meet announcement
or host before importing.

## Entries packs vs event files

CL2, HY3, and SD3 **entries** files only list events that already have at least
one swimmer or relay team. Empty events and relays with no teams will not
appear. Prefer uploading the host **EV3** or **HYV** event file together with
the entries pack (or inside the same ZIP) when you need the full schedule.
Lane4 HQ prefers EV3/HYV when both are present and does not invent missing
events from an entries-only file.

## Exporting entries

Export HY3 or CL2 when the host uses Meet Manager, or SDIF when that is the requested interchange. Review your entries and relays before sending the export to the host.

<Warning>
  An export is for your team’s entries. Lane4 HQ does not collect or merge other clubs’ entry packs.
</Warning>
